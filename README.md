# Customer Engagement & Product Utilization Analytics for Retention Strategy

A Streamlit dashboard for exploring customer engagement, product utilization, churn, and retention patterns.

## Run locally
1. Install Python 3.10 or later.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `streamlit run app.py`
4. Upload your project CSV using the sidebar.

## Deploy
Push `app.py`, `requirements.txt`, and this README to a GitHub repository, then deploy the repository from Streamlit Community Cloud.

## Important
Upload only data you are permitted to share. Avoid public uploads of confidential or personally identifiable customer information.
